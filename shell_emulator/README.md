# Эмулятор UNIX-подобной оболочки

Учебный проект на Python и Tkinter. Запуск из этой папки:

```sh
python3 main.py
```

Проверка: `python3 -m unittest discover -s tests -v`.

Этап 1: GUI, простой парсер, заглушки `ls`, `cd`, команда `exit`, ошибки.
Для интерактивной демонстрации введите по очереди `ls`, `ls /home`,
`cd /home`, `cd a b`, `unknown`, `exit extra`, `exit`.

Этап 2: `python3 main.py --vfs examples/vfs/demo.csv --script examples/startup/stage2.txt`.
Пути к VFS и скрипту отображаются при запуске.
Ошибочные строки не прерывают выполнение; `exit` завершает приложение.
`sh scripts/test_config.sh` и `sh scripts/test_errors.sh` показывают варианты
параметров. Закрывайте окно для перехода к следующему запуску.

Этап 3: VFS загружается из CSV `path,type,content`. Файлы содержат base64,
каталоги имеют пустое содержимое. Родители задаются отдельными строками.
`vfs-save output/state.csv` сохраняет память на диск; папку `output` нужно
создать заранее. `sh scripts/test_vfs.sh` проверяет три варианта VFS.

Этап 4: `ls [-a] [путь]`, `cd [путь]`, `rev файл...`, `echo [-n] текст...`,
`clear`. `cd` без аргументов возвращает в `/`; `rev` разворачивает символы
каждой строки UTF-8 файла. Скрипт: `examples/startup/stage4.txt`.

Этап 5: `mv источник назначение` переименовывает и перемещает файлы и каталоги
в памяти. Если назначение — каталог, источник помещается внутрь него;
существующий файл заменяется файлом, непустой каталог не заменяется.
Скрипт: `examples/startup/stage5.txt`. Полная демонстрация: `sh scripts/demo.sh`.
