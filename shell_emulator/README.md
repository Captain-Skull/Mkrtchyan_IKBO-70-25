# Эмулятор UNIX-подобной оболочки

Учебный проект: GUI на Tkinter, виртуальная файловая система из CSV,
стартовые скрипты и команды `ls`, `cd`, `rev`, `echo`, `clear`, `mv`,
`vfs-save`, `exit`. Требуется Python **3.10 или новее** с Tkinter.
Сторонних Python-библиотек нет.

## Быстрый запуск

Из корня репозитория:

```sh
cd shell_emulator
python3 main.py
```

В окне можно вводить команды и нажимать Enter. Имя CSV находится в заголовке,
а текущий виртуальный каталог — в приглашении `student@vfs:/$`.

Полная демонстрация команд и обработки ошибок:

```sh
sh scripts/demo.sh
```

Скрипт оставляет окно открытым для ручного ввода. Для завершения введите `exit`
или закройте окно. `clear` можно показать вручную после просмотра истории.

Если команда `python3` отсутствует, используйте `python` (в Windows — также
`py`). На этом компьютере проверен запуск через `python3` из этой папки.
Проверка доступности Tkinter: `python3 -m tkinter` — должно открыться окно.
На macOS Homebrew модуль устанавливается отдельно для версии Python,
например `brew install python-tk@3.14` для Python 3.14. В Debian/Ubuntu:
`sudo apt install python3-tk`. В официальном установщике Python для Windows
нужно включить компонент Tcl/Tk.

## Параметры запуска

```sh
mkdir -p output
python3 main.py --vfs examples/vfs/demo.csv --script examples/startup/all.txt
python3 main.py --vfs examples/vfs/minimal.csv
python3 main.py --script examples/startup/stage4.txt
python3 main.py --help
```

- `--vfs`: физический путь к CSV; по умолчанию `examples/vfs/demo.csv`
  относительно расположения программы.
- `--script`: физический путь к текстовому файлу UTF-8; по умолчанию скрипта нет.
- Явно переданные относительные пути относятся к текущему каталогу **реальной ОС**.
- При запуске окно выводит оба параметра и число загруженных узлов VFS.
- При неверном CSV/пути ошибка видна в GUI; ввод отключён до перезапуска.
- Ошибка чтения скрипта видна в GUI; после неё доступен ручной ввод.

## Команды эмулятора

| Команда | Поведение |
|---|---|
| `ls [-a] [путь]` | Вывести элементы каталога по одному в строке; `-a` показывает скрытые элементы, `.` и `..`. Для файла выводит его имя. Суффикс `/` отмечает каталог. |
| `cd [путь]` | Изменить текущий каталог. Без аргументов перейти в `/`. |
| `rev файл...` | Развернуть символы каждой строки одного или нескольких текстовых файлов UTF-8. |
| `echo [-n] [текст...]` | Напечатать аргументы через пробел; `-n` убирает завершающий перевод строки. |
| `clear` | Очистить историю на экране, сохранив состояние VFS и текущий каталог. |
| `mv источник назначение` | Переименовать или переместить файл/каталог в памяти. |
| `vfs-save путь` | Записать текущее состояние VFS в CSV реальной ОС. |
| `exit` | Закрыть приложение; изменения автоматически не сохраняются. |

Абсолютные пути начинаются с `/`. Относительные отсчитываются от текущего
каталога VFS. Поддерживаются `.` и `..`, выше `/` подняться нельзя.

Если назначение `mv` — существующий каталог, источник переносится внутрь него
с прежним именем. Файл может заменить файл, каталог — одноимённый пустой каталог
внутри назначения. Замена непустого каталога, конфликт типов, перенос корня
и перенос каталога внутрь себя запрещены. При переносе текущего каталога
или его предка приглашение обновляется.

Пути обычных команд относятся к **VFS**, путь `vfs-save` — к **реальной ОС**.
Родительский каталог для сохранения должен существовать. Существующий CSV
по указанному пути перезаписывается; для демонстрации используются файлы
в `output/`. Исходная VFS не меняется, пока явно не сохранить в её путь.

## Формат VFS

```csv
path,type,content
/,dir,
/home,dir,
/home/hello.txt,file,SGVsbG8K
```

Поля: абсолютный нормализованный путь, тип `dir`/`file`, содержимое base64.
В примере файл содержит `Hello` и перевод строки. Для каталогов содержимое
пустое. Каждого родителя нужно описать отдельной строкой; порядок строк любой.
Корень создаётся автоматически, его строку можно опустить. Допустима VFS,
состоящая только из заголовка. Все данные файлов, включая текст, кодируются
в base64; это позволяет хранить запятые, переводы строк и двоичные байты.

Примеры: `minimal.csv` — только корень; `files.csv` — несколько файлов;
`demo.csv` — файлы и каталоги глубиной не менее трёх уровней;
`invalid.csv` — намеренно ошибочный base64.

## Скрипты и проверки

В `examples/startup/` находятся отдельные сценарии этапов 2–5, общий `all.txt`
и `exit.txt` для проверки остановки скрипта. Пустые строки пропускаются;
остальные исполняются тем же обработчиком, что и ручной ввод. На экране видны
введённая команда, приглашение и результат. Ошибка содержит номер строки,
затем выполнение продолжается. `exit` прекращает скрипт и закрывает окно.

Сценарий `stage4.txt` проверяет успешный `clear`: история до этой команды
исчезает. Это ожидаемое поведение. В `all.txt` история сохраняется для просмотра.

Скрипты реальной ОС (macOS/Linux):

```sh
sh scripts/test_config.sh   # параметры по отдельности и вместе
sh scripts/test_vfs.sh      # минимальная VFS, файлы, вложенные каталоги
sh scripts/test_errors.sh   # отсутствующий скрипт, отсутствующая и неверная VFS
sh scripts/test_commands.sh # отдельные сценарии этапов 4 и 5
```

Окна открываются последовательно: закройте текущее для следующего запуска.
Для выбора интерпретатора: `PYTHON=/путь/к/python3 sh scripts/demo.sh`.
В Windows те же вызовы `python main.py --vfs ... --script ...` можно выполнять
в PowerShell, `.sh` запускаются через Bash, например Git Bash.

## Ограничения

Это учебный эмулятор с явно указанными режимами команд. Парсер разделяет
ввод по пробельным символам: кавычки, имена с пробелами в командах, конвейеры,
перенаправления, переменные, маски файлов, запуск системных процессов,
символические ссылки и права доступа не реализованы. `rev` требует путь
к файлу; интерактивный stdin не предусмотрен. Если один из файлов `rev`
не читается, команда целиком возвращает ошибку. UTF-8 разворачивается по
символам Python, составные графемы отдельно не обрабатываются.
