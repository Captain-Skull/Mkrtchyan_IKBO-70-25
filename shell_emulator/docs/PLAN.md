# План реализации

Цель: выполнить пять этапов учебного задания и подготовить объяснение для защиты.
Решение: Python 3.10+, Tkinter, только стандартная библиотека; отдельные модули
для GUI, исполнения команд и VFS. Все изменения — в папке `shell_emulator`.
Пользователь поручил полную реализацию; технические решения выбраны исполнителем.

1. REPL: `shell.py`, `gui.py`, `main.py`; сначала тесты пустого ввода,
   заглушек, неизвестной команды и аргументов `exit`, затем код и коммит.
2. Конфигурация: `config.py`, `startup.py`, примеры и shell-скрипты;
   тесты значений CLI и продолжения после ошибки; затем код и коммит.
3. VFS: `vfs.py`, CSV-примеры и `vfs-save`; тесты загрузки, ошибок,
   двоичных данных, сохранения и неизменности источника; затем код и коммит.
4. Команды: реализация `ls`, `cd`, `rev`, `echo`, `clear`;
   тесты абсолютных/относительных путей, скрытых файлов, Unicode,
   неверных аргументов и файлов вместо каталогов; затем код и коммит.
5. Перемещение: `mv`; тесты перемещения поддерева, замены, конфликтов,
   запрета циклов и обновления текущего каталога; затем код и коммит.
6. Итог: полный прогон unittest, проверка GUI и скриптов, README,
   руководство для защиты и отдельный коммит документации.

Особые проверки: ошибочный UTF-8 и base64; неверная структура CSV;
попытки выйти выше корня; перемещение предка текущего каталога;
`exit` посреди стартового скрипта. Ошибки команд не останавливают скрипт,
`exit` закрывает окно и прекращает скрипт. Ошибка загрузки VFS фатальна:
сообщение в GUI, поле ввода отключено. Пути CLI относительны каталогу
запуска ОС; пути обычных команд относятся к VFS, `vfs-save` — к ОС.
